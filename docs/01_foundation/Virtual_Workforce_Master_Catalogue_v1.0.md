# Virtual Workforce Master Catalogue

- Worker ID
- Role
- Department
- Workforce class
- Mission
- Responsibilities
- Inputs / outputs
- Skills
- Knowledge sources
- Tools
- Permissions
- Authority
- Supervisor
- Escalation rules
- Workflow triggers
- KPIs
- Cost profile
- Operating policy
- Audit history

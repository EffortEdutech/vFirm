## Purpose

Connect clients, Virtual Firms, specialist professionals, AI/human capacity and partner firms without reducing the platform to a freelance marketplace.

## Core principles

1. The marketplace is multi-party professional production, not Fiverr-style gig work.
2. Mandatory credentials and jurisdiction rules outrank price.
3. Professional identity and Virtual Firm identity are distinct.
4. Trust is multi-dimensional; credentials remain separate from ratings.
5. Start with a trusted specialist network before global marketplace liquidity.
6. Data isolation and conflict checks are mandatory.

## 4. Accepted limitations

The following limitations remain accepted constraints:

1. Release 5 remains controlled trusted-network capability, not a public marketplace.
2. External credential, insurance, professional board, and identity registry integrations are represented by controlled evidence references unless later integrated explicitly.
3. Network matching is qualification-gated but not a capacity-economy or price-ranking engine.
4. UI coverage may still trail API/control-plane depth.
5. VF-24 ecosystem intelligence and public observatory publication remain out of scope.
6. Live payment movement remains out of scope.
7. Liability language remains jurisdiction-, engagement-, insurance-, and entity-structure-dependent.

## 5. Preserved boundaries

This decision does not authorize:

- public marketplace launch;
- marketplace/ecosystem implementation;
- VF-24 ecosystem intelligence publication;
- price-first allocation;
- public ratings as credential substitute;
- autonomous regulated award;
- autonomous regulated approval;
- direct LLM-to-final regulated output;
- uncontrolled tenant data sharing;
- live payment movement;
- uncontrolled production expansion.

## 6. Authorized next work

Authorized next work is limited to preparing the later Marketplace / Ecosystem Intelligence scope decision gate.

That gate must clearly separate:

- marketplace publication;
- qualification-first matching;
- marketplace-origin collaboration contracts;
- capacity economy signals;
- VF-24 ecosystem intelligence;
- privacy and aggregation thresholds;
- governance review and explicit implementation authorization.

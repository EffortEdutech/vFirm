# Virtual Firm Release 3 Evidence Pack Template v1.0

## 1. Purpose

This template defines the evidence required to close Release 3. Release 3 is accepted only if the Virtual Firm Factory provisions a second controlled local firm from blueprints and proves authority, tenant isolation, auditability, and export.

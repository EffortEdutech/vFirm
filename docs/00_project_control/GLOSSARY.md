# Virtual Firm Platform Glossary

| Term | Definition |
|---|---|
| Virtual Firm | The professional service business operated by a principal using platform-provided infrastructure, virtual workforce and network capability. |
| Principal | Human professional/owner responsible for the firm and its accountable decisions. |
| Virtual Employee / AI Worker | Governed AI worker instance with role, skills, knowledge, tools, memory, permissions, authority, supervisor, workflow, budget and audit identity. |
| Virtual Workforce | Collection of common, specialist, management and governance AI workers assigned to a Virtual Firm. |
| Practice Pack | Domain-specific bundle of knowledge, tools, workflows, rules, templates, QA and regulatory requirements. |
| Service Delivery Pack | Configuration required to execute one defined professional service. |
| Service Product | Productized professional service with scope, inputs, outputs, workflow, pricing, SLA, quality and compliance rules. |
| Professional Service SKU | Machine-readable commercial identifier for a productized professional service. |
| Firm Blueprint | Machine-readable definition of a Virtual Firm and its modules, workforce, services, tools, knowledge, policies and governance. |
| Workforce Blueprint | Machine-readable set of worker instances/templates assigned to a firm. |
| Governance Pack | Domain/profession governance rules. |
| Jurisdiction Pack | Jurisdiction-specific professional, regulatory, commercial and data rules. |
| Virtual Principal | AI executive intelligence service supporting the human principal; never a licensed-professional substitute. |
| Control Plane | Platform infrastructure that provisions, governs, secures, meters and monitors firms and services. |
| Firm Runtime | Execution environment for Virtual Firm workflows and AI workers. |
| Evidence Bundle | Auditable package of inputs, sources, rules, calculations, QA, exceptions, review and approval supporting a professional deliverable. |
| Capability | Machine-readable professional capability used for matching, network capacity and service delivery. |
| Federation | Temporary or persistent collaboration of multiple Virtual Firms/professionals around a project or enterprise need. |
| PCE | Professional Capacity Equivalent; service-specific normalized measure of verified deliverable capacity. |
| No Orphan Regulated Work | Every regulated deliverable must trace to a responsible authorized human professional. |
| No Silent Approval | Approval must be explicit and recorded; absence of objection is never approval. |

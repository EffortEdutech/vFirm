- firm-to-firm subcontract
- prime contractor / lead professional
- virtual consortium

- enterprise private federation

## Project data boundary

Cross-firm collaboration should use a controlled Project Data Room. External firms receive only what they need.

No automatic access to:
- entire firm knowledge
- unrelated client data
- internal pricing
- private strategies

## Conflict checks

Before collaboration:
- existing clients
- competitors
- project restrictions
- confidentiality conflicts
- regulatory conflicts

## Authority rule

Network collaboration must never obscure who produced, reviewed, approved and signed a regulated deliverable.

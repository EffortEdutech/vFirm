# Virtual Firm Platform

**Architecture baseline:** VF-00 → VF-24  
**Repository baseline:** v1.0  
**Purpose:** Codex-ready source repository for the Virtual Firm Platform architecture.

## Core proposition

> **One Professional. One Virtual Firm. A Whole Workforce.**

A qualified professional brings expertise, judgement, credentials, reputation and regulated authority. The platform provides professional practice infrastructure: AI workforce, business systems, commercial support, client operations, governance, tools, network capability and institutional memory.

## Core equation

**Professional Expertise + Virtual Workforce + Shared Business Infrastructure = Virtual Firm**

## Repository conventions

- `VF-XX` identifies architecture documents.
- Practice-specific assets live under `12_service_delivery/`.
- Productized services and Service SKUs live under `13_productization/`.
- Firm Blueprints live under `14_firm_launch/`.
- Cross-firm and enterprise federation assets live under `15_network_federation/`.
- Shared schemas, events, APIs, taxonomies and policies live under `18_shared_assets/`.
- Vertical reference implementations live under `19_reference_implementations/`.
- Build artifacts belong under `20_implementation/`.
- Tests/evaluations belong under `21_testing_validation/`.

## Important source-status note

This repository was consolidated from the architecture discussion. VF-16 through VF-24 were available in the latest conversation context in detailed form and are represented as direct consolidations. Some earlier modules (especially VF-03 through VF-15) were available as architecture summaries rather than exact verbatim historical prose, so their files are marked **CONSOLIDATED/RECONSTRUCTED**. VF-01 and VF-02 are intentionally marked **DRAFT TO FORMALIZE**.

Do not treat reconstructed wording as a legal or regulatory specification. The architecture intent and module boundaries are preserved.
